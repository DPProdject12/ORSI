# Право на текст — учебное веб-приложение

## Запуск

Распакуйте архив и откройте `index.html` в современном браузере (Chrome, Edge, Firefox). Сервер, установка зависимостей и подключение к интернету не требуются. Все три файла приложения (`index.html`, `style.css`, `cases.js`, `app.js`) должны оставаться в одной папке.

## Работа студента

1. При первом запуске случайно выбирается один из 10 вариантов. Текущий вариант закрепляется за попыткой и сохраняется в браузере после обновления страницы. Кнопка «Новый вариант» выбирает другой вариант; во избежание потери данных предварительно сохраните отчёт или экспортируйте JSON. Четыре последних случайно выбранных варианта исключаются из повторного выбора.
2. Прочитайте текст и откройте досье для сопоставления. Важно: все кейсы и досье являются искусственно подготовленными учебными материалами. Даже когда названия документов или организации совпадают с реальными, приведённые для упражнения сведения не предназначены для использования как проверенные реальные источники.
3. Добавляйте карточки проблем: фрагмент, тип, источник, обоснование, исправление. Если перед нажатием «Добавить проблему» выделить фрагмент исходного текста, он автоматически попадёт в карточку.
4. Заполните заключение и сведения о студенте. Данные сохраняются локально в браузере; удаление данных сайта, смена браузера или устройства могут их удалить. Для переноса скачайте JSON и импортируйте его на другом устройстве с этой же версией приложения.
5. Нажмите «Сформировать отчёт». В окне печати браузера выберите «Сохранить как PDF». Отчёт включает ФИО, группу, дату, полный исходный текст, карточки, вывод и досье. Параметры печати и имя файла задаются браузером.

## Устройство проекта

- `index.html` — структура интерфейса.
- `style.css` — оформление, адаптивная версия и печать отчёта.
- `cases.js` — 10 учебных вариантов и их досье. Варианты можно редактировать, сохраняя структуру объекта.
- `app.js` — случайный выбор, карточки, локальное сохранение, импорт/экспорт и отчёт.

Серверного хранения, автоматической отправки преподавателю и автоматической оценки нет. Просмотр досье доступен студенту, так как оно предназначено для анализа. Правовая оценка выполняется человеком.
